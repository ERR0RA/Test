# Sparx Neon

Fast neon AI helper for Sparx Maths, Sparx Reader, and Sparx Science. Solves questions, auto-fills supported answer types, and remembers bookwork codes.

## Features

- Solves text and image questions
- Auto-fills answers into the page
- Tracks bookwork codes so you never fail a bookwork check
- Handles equations, fractions, multiple choice, and dropdowns
- Supports Sparx Maths, Reader, and Science domains
- Faster text-only scans by skipping screenshots when no image is detected
- Free models (Groq, Gemini) and paid options (Claude Sonnet, Haiku)

## Install — Desktop (Chrome, Edge, Brave, Opera)

1. Download this repo — click the green **Code** button above, then **Download ZIP**
2. Unzip the folder
3. Open Chrome and go to `chrome://extensions`
4. Turn on **Developer mode** (top right toggle)
5. Click **Load unpacked** and select the unzipped folder
6. Done — open Sparx Maths and press **Shift+S** to open the solver

## Install — Android (Kiwi Browser)

Regular Chrome on Android can't load extensions, but **Kiwi Browser** can (it's a free Chromium-based browser on the Play Store).

1. Install **Kiwi Browser** from the Google Play Store
2. Download this repo — green **Code** button → **Download ZIP**
3. Open Kiwi's file manager (or any file app) and extract the ZIP
4. In Kiwi, tap the **⋮ menu** → **Extensions**
5. Turn on **Developer mode** (top right)
6. Tap **+ (from .zip/.crx/.user.js)** and pick the ZIP you downloaded — or **Load unpacked** and pick the extracted folder
7. Open Sparx Maths in Kiwi and tap the extension icon to open the solver

## iPhone / iPad

Not supported. Apple blocks extension sideloading on iOS/iPadOS — Safari and Chrome on iOS won't run this extension. Use a laptop or an Android device.

## Getting an API key

Click the extension icon, go to the **API Key** tab, and click **"How do I get one?"** for step-by-step instructions. Groq and Gemini are free.

## Usage

- **Solve with AI** — shows a step-by-step explanation
- **Auto-fill** — solves and fills the answer automatically
- Bookwork answers are saved and shown when you get a bookwork check

## Privacy

Your API key is stored locally. No data is collected or sent to us. Questions are sent directly to the AI provider you choose using your own key.
