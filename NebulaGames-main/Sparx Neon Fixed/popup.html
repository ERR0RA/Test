How do I get an API key?

Groq FREE

  1. Go to console.groq.com
  2. Sign up with Google or email
  3. Go to API Keys in the sidebar
  4. Click Create API Key, copy it
  5. Paste it here and select Groq GPT-OSS

Fast and free. Text questions only (no images).

Gemini FREE

  1. Go to aistudio.google.com/apikey
  2. Sign in with Google
  3. Click Create API Key, copy it
  4. Paste it here and select a Gemini model

Free with generous limits. Supports images.

Anthropic (Claude) PAID

  1. Go to console.anthropic.com
  2. Sign up and add billing (pay-as-you-go)
  3. Go to API Keys
  4. Click Create Key, copy it
  5. Paste it here and select Sonnet or Haiku

Most accurate. Haiku is cheaper, Sonnet is smarter. Both support images.
