Sparx Solver Fixed

Fast, reliable, and easy to set up Chrome extension.

Download ZIP Archive

1. Installation

  1. Extract the .zip file to a folder.
  2. Navigate to chrome://extensions in your browser.
  3. Enable Developer Mode (top right toggle).
  4. Click Load unpacked and select the extracted folder.

2. API Key Setup

A Gemini API key is required to power the solver.

  1. Visit Google AI Studio.
  2. Generate a free API key.
  3. Paste the key into the extension popup.

⚠️ Important Notes

  • Never share your API key with anyone else.
  • Educational use only: Use this as a study aid, not for academic dishonesty.
  • Supported browsers: Chrome, Brave, Edge, and Opera.
  • If the extension fails to load, ensure you selected the folder containing manifest.json.
